# AutoStream website

The site at [getautostream.app](https://getautostream.app): what AutoStream makes, downloads and tutorials.

Plain HTML and CSS in `docs/`, served by GitHub Pages. No build step; push to `main` and it updates.
The app itself lives at [hardikneeravsharma/AutoStream](https://github.com/hardikneeravsharma/AutoStream).
