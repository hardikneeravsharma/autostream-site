Install AutoStream

Download it, open it, and choose what you want it to do.

About five minutes

On Windows

  1. Download the installer

    Download AutoStream for Windows and open the file. Use the installer unless you need the portable version: if you would rather not install anything, take the portable zip, unzip it somewhere it can stay, such as C:\AutoStream, and open AutoStream from there.

  2. If Windows warns you, choose Run anyway

    AutoStream is not signed with a paid certificate yet, so Windows does not know who made it and says it protected your PC. Choose More info, then Run anyway. You only see this once. To check the file first, compare it with the checksum published beside it on the release page; the source code is public.

  3. Choose Just make clips

    The first time it opens, AutoStream asks what you want it to do. Just make clips is marked recommended and is ready in seconds: no account and nothing else to install. The one video tool it needs, it offers to install for you the first time you make clips.

    Want it to go live for you too? Choose Stream and clip instead, or switch it on later in Settings. That is the last tutorial.

  4. Make your first clips

    That is it. Next: make clips from a recording.

Closing the window does not quit. AutoStream keeps running in the system tray, by the clock, so it can notice when you start a game. To quit, use Quit in the window or in the tray icon's menu.

On a Mac

The Mac app makes clips and song reels. Automatic live streaming is Windows only. Record on your PC, copy the video over, and cut it on the Mac.

  1. Download the right version

    Apple Silicon for an M1, M2, M3 or newer, or Intel for older Macs. Not sure? Apple menu, About This Mac, and look at the chip. macOS 11 or newer.

  2. Install the video tool

    AutoStream uses a free tool called ffmpeg to cut video. Paste this into the Terminal app (it needs Homebrew):

    brew install ffmpeg-full

  3. Open it the first time

    The Mac refuses an app it has not checked yet. Open System Settings, then Privacy & Security, scroll down and choose Open Anyway.

Where your videos go

Recordings, clips and reels are saved in your Videos folder, under AutoStream. Reinstalling or updating never touches them, and AutoStream never deletes a recording.

Start AutoStream when Windows starts

Finish setup first. Then open PowerShell as Administrator and run the script that sits next to AutoStream.exe, changing the path to wherever AutoStream lives:

powershell -ExecutionPolicy Bypass -File "C:\AutoStream\Run-At-Startup.ps1"

It registers a scheduled task that starts AutoStream 45 seconds after you log in, starts it now, and checks it is running. Add -Remove to undo it. Administrator is only needed to register the task; AutoStream itself runs as you, because it has to see your desktop and your games.

Why the full ffmpeg on a Mac

The plain Homebrew ffmpeg cannot draw text, so captions and titles would be missing. ffmpeg-full can.

Checking the download

Every release is built on GitHub's own machines from the public source, with a SHA-256 checksum next to each file on the releases page.
